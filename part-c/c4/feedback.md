\# C4 — Non-Technical Listener Feedback



\## What I Explained

I explained that `checkSeatAvailability` calculates how many seats are available on a flight and checks whether the number of seats requested can be accommodated.



\## What the Listener Understood

The listener explained that the feature lets users know the seats available on a selected flight, rejects requests when there are not enough seats, and does not make reservations or bookings. It only checks seat availability.



\## What I Learned

The listener understood the main purpose of the feature and recognised that checking seat availability is different from making a reservation. I also learned that I should clearly explain that the function checks whether the requested number of seats can fit into the remaining capacity.
